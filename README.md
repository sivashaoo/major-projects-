# Major Projects — Electrical & Electronics Engineering

A curated portfolio of major engineering projects focused on embedded systems, IoT, electrical equipment monitoring, automation, and mine-vehicle safety.

## Projects

### 1. Smart Waste Segregation
Automated waste segregation using sensors and motorized sorting mechanisms.

**Source repository:** [SMART-WASTE-SEGREGATION](https://github.com/sivashaoo/SMART-WASTE-SEGREGATION)

### 2. Transformer Health Monitoring
IoT-based monitoring of transformer/electrical equipment parameters to support condition monitoring and early fault awareness.

**Source repository:** [transformer-health-monitoring](https://github.com/sivashaoo/transformer-health-monitoring)

### 3. Mine Vehicle Safety in Low Visibility
A safety-focused system for mine vehicles operating in fog and low-visibility conditions, using sensing and alert/control logic.

**Source repository:** [mine-vehicle-safety](https://github.com/sivashaoo/mine-vehicle-safety)

## How this portfolio is organized

This repository is the central index for the three projects above. Their implementation files, commit histories, and existing documentation remain in the linked source repositories. This avoids creating duplicate copies that can become outdated.
