## Engineering Workflow

Every project aims to follow this disciplined process:

1. **Define** the problem, constraints, inputs/outputs, and safety considerations  
2. **Design** the sensing, control, power, and communication architecture  
3. **Build & document** readable firmware, pin tables, and setup instructions  
4. **Test & calibrate** — record conditions, expected vs actual behaviour, and limitations  
5. **Iterate** while clearly separating what is currently working from what is planned

## Documentation Standards

- Every project README clearly states objective, components, wiring, setup, and limitations  
- Starter / concept projects are labeled honestly — never presented as production-ready systems  
- Hardware behaviour must always be validated on real boards  
- Proper safety practices (isolation, fuses, current limits, low-voltage setups) are emphasized  
- No secrets (Wi-Fi passwords, API keys, tokens) are ever committed
